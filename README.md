# Treipo Travels Website

Static, mobile-responsive website for Treipo Travels.

## Before publishing
1. Open `assets/script.js`.
2. Replace `91XXXXXXXXXX` with the real WhatsApp/phone number in international format, without `+` or spaces.
3. Replace `https://treipo-travels.github.io/` in the HTML canonical tags and `sitemap.xml` if your GitHub username or final domain is different.
4. Replace the CSS vehicle illustrations with real fleet photos later if desired.

## Files
- `index.html` — Home
- `vehicles.html` — Fleet
- `services.html` — Services
- `contact.html` — Quote form
- `assets/style.css` — Design
- `assets/script.js` — WhatsApp, phone and form logic
- `robots.txt`
- `sitemap.xml`
